## 2. 发现并修复的真 bug

**自撞库误报强重复**：`确认归档`先 `save_manual_review` 写记录入库，`archive_confirmed` 去重时匹配到自己 → `强重复(matching file hash)` 拒绝（用户实测两张均复现）。

修复 `deduplicator.check`：跳过"同路径+同哈希"的已登记记录（文件自身）；不同路径同哈希仍判真强重复。修复后两条已存记录评估为 `新发票`+eligible，无残留副作用。

顺带修复 GUI bug：`QPushButton.clicked` 会携带 `checked=False`，落到 `on_done` 参数后 `on_done()` 调用抛 `TypeError: 'bool' object is not callable`——5 处改为 `callable(on_done)` 守卫。

回归测试 `test_reviewed_record_is_not_self_duplicate` 双向覆盖。
