# S3.3 月度台账验收

## 1. 结构（对照《2026.8报销.xlsx》可见列）

Sheet1 `报销流水`：序号 | 日期 | 姓名 | 金额 | 类别 | 凭证类型 | 费用发生地 | 备注 | 报销状态
Sheet2 `发票明细`：序号 | 发票号码 | 开票日期 | 价税合计 | 税额 | 购买方 | 销售方 | 发票内容 | 文件名 | PDF路径 | 归档状态 | 审核状态 | 重复状态 | 来源

差异说明：流水表在可见列基础上追加 `报销状态` 列——区分"发票档案"与"报销流水"，避免把所有收到的发票直接计为已报销（用户明确要求保留此区别）。

## 2. 字段来源规则

| 列 | 来源 |
|---|---|
| 日期 | 开票日期 `YYYY.MM.DD`（费用发生日期留待业务层） |
| 姓名 | 记录 reimburser → 配置默认 → `待指定`；绝不用购买方企业名顶替 |
| 金额 | 价税合计，数值类型，0.00 格式 |
| 类别 | 可配置关键词字典建议；0 或多命中 → `待确认` |
| 凭证类型 | 固定 `电子发票` |
| 费用发生地 | 仅人工填写，无证据恒空 |
| 备注 | **恒空** |
| 报销状态 | 未确定/报销/不报销 |

## 3. 真实数据验证（28 份 eligible 记录，纯内存标记后导出 /tmp）

- 流水行数 **28**，合计 **¥12,947.02** = 真实金额和（分毫不差）
- 日期升序；月份分布 2026-10 × 28
- 备注列 **全空** ✅
- 类别自动建议分布：差旅费 10 · 业务招待费 5 · 待确认 13（不确定不猜）

## 4. 格式/工程验证（openpyxl 断言）

- 冻结首行 A2 + 自动筛选 + 列宽
- 合计行金额 `round(sum,2)` 与行和一致
- **重复导出零重复**：export 是纯函数，二次生成后数据行仍 1
- 原子替换：tmp + `os.replace`
- `export_monthly_ledger` 只统计 `archive_status ∈ {auto_archived, manually_archived}` 且月份匹配的记录——待处理/审核中条目不进台账
