# 网易邮箱附件同步 · 用户指南

orgTool 2.0 可以连接你的网易邮箱（163 / 126 / 企业邮箱），把邮件里的 PDF
附件（发票、账单、收据）自动下载到"发票归档_待处理"，进入既有的发票
识别与归档流程。

## 一、准备授权码（重要）

**不要填邮箱登录密码。** 网易邮箱第三方客户端必须使用"客户端授权码"：

1. 浏览器登录 `mail.163.com`（或 `mail.126.com`）。
2. 顶部"设置" → "POP3/SMTP/IMAP"。
3. 开启"IMAP/SMTP 服务"，按提示用手机验证，生成**客户端授权码**。
4. 复制授权码备用（它只会显示一次）。

> 授权码保存在本机系统凭证管理器（macOS 钥匙串 / Windows 凭据管理器），
> 不会写入配置文件、日志或仓库。

## 二、添加邮箱账户

1. 打开"发票管理"页 → "邮箱同步"区域 → "添加邮箱"。
2. 填写邮箱地址 —— `@163.com`/`@126.com` 会自动匹配服务器预设；
   企业邮箱选择"网易企业邮箱"预设（`imaphz.qiye.163.com`），不要混用
   个人邮箱服务器地址。
3. 粘贴**授权码**。
4. 点击"获取文件夹列表"勾选要同步的文件夹（支持中文文件夹名）。
5. 点击"测试连接"——依次验证连接、登录、IMAP ID、文件夹、搜索、读取，
   失败时会指出具体阶段。
6. 保存。

可选设置：

- **同步间隔**：默认 15 分钟（1–1440 可调）。
- **发票导入**：默认开启，下载的 PDF 自动复制到待处理目录。

## 三、历史补抓（第一次用）

1. 选中账户 → "历史补抓"。
2. 对话框会显示**服务器实际返回的文件夹列表**。
3. 选择"扫描服务器当前可见的全部历史邮件"，或按日期范围扫描。
4. 开始后可随时"暂停/恢复/取消"；中断后重新启动会从断点继续，
   已下载的不会重复。

> 注意：部分网易账户在网页设置中限制了"客户端收取范围"（如仅近 30 天）。
> 这是服务器侧限制，不是程序问题——实际可见数量以服务器返回为准。

## 四、自动同步新邮件

- 勾选"应用运行期间自动同步"后，程序按设定间隔轮询新邮件。
- **自动同步仅在应用运行期间执行，退出应用后不再同步**（第一版不做
  后台常驻服务）。
- 新下载的 PDF 会立即出现在发票扫描结果里。

## 五、文件去了哪里

```
发票管理/
  邮件原始附件/<账户>/<YYYYMM>/   # 原始附件，不覆盖
  发票归档_待处理/                 # PDF 原件 + .source.json 来源信息
```

每张下载的 PDF 旁边有 `.source.json` 记录来源（账户、文件夹、邮件 ID、
主题、发件人、收件时间、SHA-256）；归档后信息保留在发票记录里。

## 六、去重规则

- 同一封邮件的同一附件：只下载一次（重跑同步不会产生重复文件）。
- 不同邮件但内容完全相同的附件：只保留一份文件。
- 同名但内容不同的附件：两个文件都保留，自动改名。

## 七、常见问题

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `AUTH_FAILED` | 用了登录密码/授权码错误 | 重新生成授权码再试 |
| `IMAP_ID_UNSUPPORTED` | 服务器要求客户端 ID 被拒 | 更新到最新版本重试 |
| `MAILBOX_SELECT_FAILED` | 文件夹不存在/无权限 | "获取文件夹列表"重新选择 |
| `SERVER_HISTORY_LIMIT` | 账户设置限制历史范围 | 网页版调整"客户端收取范围" |
| `NETWORK_TIMEOUT` 多次重试 | 网络断开/服务器限流 | 恢复网络后点"立即同步" |
| `INVALID_PDF` | 附件损坏或不是真 PDF | 该附件会被标记失败，不影响其他 |

查看日志：`runtime/logs/mail_sync.log`（日志不含授权码和邮件正文）。
